# Gustavo Henrique | Portfólio Premium de Conversão (CRO)

Este repositório contém o código-fonte do portfólio profissional de **Gustavo Henrique**, Especialista em implantação de Landing Pages de alta conversão.

## 🚀 Novidades da Versão 2.0 (Redesign)

- **Identidade Visual "Emerald & Obsidian"**: Transição do antigo layout vermelho para uma estética muito mais limpa, moderna e tecnológica (tons de verde esmeralda, grafite e preto carvão no estilo Stripe/Supabase).
- **Tipografia Otimizada**: Utilização do par de fontes **Outfit** (títulos proeminentes e modernos) e **Inter** (leitura confortável para textos corporativos).
- **Simulador Interativo de CRO / ROI**: Uma calculadora interativa no site onde potenciais clientes podem arrastar sliders de Tráfego Mensal, Conversão Atual, Conversão com Landing Page Otimizada e Ticket Médio, para ver na hora o retorno financeiro extra estimado que o trabalho traz.
- **Filtro Dinâmico de Projetos**: Organização em abas permitindo filtrar entre "Todos", "Landing Pages" e "Projetos Institucionais".
- **Performance e GPU**: Otimizações nos efeitos de movimento, remoção de redundâncias de filtros em dispositivos móveis e melhora do carregamento para pontuar melhor nos testes de Core Web Vitals.

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Semântico e estruturado)
- **Tailwind CSS** (Estilização base e utilitários rápidos)
- **Vanilla CSS** (Gradientes avançados, grid neon, glassmorphism e animações personalizadas de alto desempenho)
- **Vanilla JavaScript** (Lógicas interativas da calculadora, abas de filtro, lightbox de certificados e escuta de scroll/movimento)
- **Lucide Icons** (Ícones vetoriais modernos)

## 📁 Estrutura de Arquivos

- `index.html`: Arquivo HTML principal do site, contendo a estrutura semântica e SEO otimizado.
- `style.css`: Folha de estilo personalizada contendo as variáveis de cores (Emerald & Obsidian), animações e regras responsivas.
- `script.js`: Toda a lógica de interação (modal de certificados, simulador de CRO, filtros de portfólio e animações no viewport).
- `/certi*.png`: Certificações e formações técnicas exibidas no portfólio.
- `capa.jpg`: Imagem de perfil principal de Gustavo Henrique.
